# 通知中心（notice）

客戶通知網頁。**這個資料夾不放任何客戶資料。**

## 結構

```
notice/
├─ index.html      顧問用：通知頁產生器（有密碼）
├─ pay.html        通用繳費通知
├─ README.md
└─ fire/           住宅火險專用
   └─ pay.html     火險繳費通知
```

之後每多一種險別，就在 notice/ 底下開一個子資料夾：
`car/`（車險）、`health/`（醫療）、`life/`（壽險）⋯⋯ 做法完全一樣。

## 運作方式

客戶資料寫在**連結的網址裡**，不寫進網站檔案：

```
fire/pay.html?a=2286&n=60952761113714&d=2026-10-16
```

| 參數 | 意思 | 範例 |
|---|---|---|
| `a` | 應繳金額（純數字） | `2286` |
| `n` | 銷帳編號（可省略） | `60952761113714` |
| `d` | 繳費期限（西元 YYYY-MM-DD） | `2026-10-16` |
| `c` | 承保公司 | `國泰世紀產物保險` |
| `t` | 頁面標題 | `住宅火險　保費繳款通知` |
| `p` | 險種說明 | `住宅火災及地震基本保險　一年期` |

全部省略時，頁面會顯示「請見繳費單」，不會出錯。

## 規則

1. **不放客戶姓名、身分證字號、地址、電話**到這個資料夾的任何檔案。
2. **客戶連結只傳給本人**，不貼公開場合。連結本身就等於那份資料。
3. 新增通知類型（續保提醒、補件通知、理賠進度）時沿用同一做法：版型放檔案，資料放網址。
